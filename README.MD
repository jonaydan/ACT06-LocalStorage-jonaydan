# 🎯 ACT-LocalStorage : Maîtrisez le localStorage en 4 exercices ludiques !

## 📖 Introduction

Bienvenue dans cette série d'exercices pratiques pour maîtriser le **localStorage** ! 🚀

Le localStorage est un outil puissant qui permet de stocker des données directement dans le navigateur de l'utilisateur. Que ce soit pour sauvegarder les préférences d'un utilisateur, créer des applications qui se souviennent de leur état, ou simplement pour apprendre les bases du stockage côté client, cette série d'exercices vous guidera pas à pas.

Chaque exercice est conçu pour être **progressif** et **ludique** - vous verrez vos compétences s'améliorer à chaque étape ! 🎮


> Les exercices sont disponibles dans le dossier [exercices](./exercices), vous répondez à chaque exercice dans le fichier de l'exercice.

> Chaque fichier html intègre le framework [Pico.css](https://picocss.com/) pour une meilleure expérience utilisateur et ne pas perdre de temps à réaliser les styles.

Avant de commencer, prenez quelques minutes pour découvrir ou réviser le fonctionnement du localStorage grâce à la ressource dédiée.

## 🎯 Les exercices


### 📝 Exercice 1 : Premiers pas avec localStorage
**Objectif :** Comprendre les opérations de base

- ✅ Créer une page avec un champ texte et deux boutons "Sauvegarder" et "Charger"
- ✅ Implémenter la sauvegarde d'une valeur dans localStorage
- ✅ Implémenter la récupération et l'affichage de cette valeur
- ✅ Ajouter un bouton "Effacer" pour supprimer la donnée

*C'est le moment de faire vos premiers pas !* 🚶‍♂️

### ⚙️ Exercice 2 : Gestionnaire de préférences utilisateur
**Objectif :** Manipuler différents types de données

- ✅ Créer un formulaire avec : nom, couleur préférée, langue, mode sombre/clair
- ✅ Sauvegarder automatiquement à chaque modification
- ✅ Restaurer les préférences au chargement de la page
- ✅ Gérer les valeurs par défaut si aucune préférence n'existe

*Votre site se souviendra de tout !* 🧠

### 📋 Exercice 3 : Todo List persistante
**Objectif :** Travailler avec des tableaux et objets

- ✅ Créer une application de liste de tâches
- ✅ Stocker un tableau d'objets (id, texte, terminé, date)
- ✅ Implémenter l'ajout, la suppression et la modification du statut
- ✅ Maintenir la persistance dans le localStorage

*Plus jamais de tâches perdues !* ✨

### 🛒 Exercice 4 : Système de panier d'achat
**Objectif :** Gérer des données complexes

- ✅ Simuler des produits avec prix, quantités
- ✅ Ajouter/retirer des articles du panier
- ✅ Calculer et afficher le total en temps réel
- ✅ Conserver le panier entre les visites

*Votre panier vous attendra toujours !* 🛍️


## 🛡️ Bonnes pratiques

Chaque exercice devrait inclure :
- 🔒 **Gestion d'erreurs** robuste
- ✅ **Validation des données** appropriée
- 🌐 **Tests de compatibilité navigateur**
- 📱 **Interface responsive** et accessible
